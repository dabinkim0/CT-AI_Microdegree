# Claude for Slides에 붙여 넣을 프롬프트

사용법: Chrome에서 Google Slides 덱(CT&AI Micro Degree)을 연 상태로 Claude 사이드 패널을 열고, 아래 프롬프트를 붙여 넣은 뒤 `docs/slides_spec.md`(슬라이드별 스펙)를 함께 첨부한다. 첨부가 안 되면 `slides_spec.md` 본문을 프롬프트 아래에 그대로 이어 붙인다. 30장을 한 번에 만들면 끊길 수 있으니 1차(S1~S16), 2차(S17~S30)로 나눠 요청하는 것을 권장한다.

---

```
지금 열려 있는 Google Slides 덱(CT&AI Micro Degree)의 **기존 스타일을 그대로 따라** 수업 슬라이드 30장을 덱의 맨 뒤에 추가해줘. 기존 슬라이드는 수정하지 마.

[스타일 규칙]
- 기존 슬라이드의 테마·레이아웃(마스터)·글꼴·글자 크기·색상 팔레트·여백·제목 위치를 그대로 쓴다. 새 글꼴이나 새 색을 만들지 않는다.
- 섹션 구분 슬라이드가 기존 덱에 있으면 같은 레이아웃으로 "목요일: 배경지식", "토요일: 실습" 구분 슬라이드를 각 파트 앞에 넣는다.
- 한 슬라이드에 본문 글머리표는 최대 5개, 한 줄은 25자 안팎. 문장 대신 구(句)로 쓴다.
- 표가 지정된 슬라이드는 Google Slides 표 객체로 만든다(이미지 아님). 표는 6행 이하로 유지하고 넘치면 두 장으로 나눈다.
- "시각자료" 항목은 실제 이미지가 아직 없으므로, 기존 덱의 이미지 영역 스타일(테두리·그림자 등)을 따르는 **회색 플레이스홀더 도형**을 넣고 그 안에 캡션 텍스트를 쓴다. 예: "[리포트 #s1 재생 화면 캡처]".
- 코드가 지정된 슬라이드는 고정폭 글꼴 텍스트 상자 하나로 넣고, 4줄 이하로 유지한다.
- 각 슬라이드의 "발표자 노트" 내용은 슬라이드 본문이 아니라 스피커 노트에 넣는다.
- 슬라이드 오른쪽 아래(또는 기존 덱의 페이지 번호 위치)에 "목 S1" / "토 S17" 같은 짧은 태그를 작은 글씨로 넣는다.
- 한국어로 쓰되 모델 이름·파라미터 이름(CFG, seed 등)은 영문 그대로 둔다.

[내용]
첨부한 slides_spec.md의 S1부터 S30까지를 순서대로 한 장씩 만든다. 각 항목의 의미:
- 제목 → 슬라이드 제목
- 본문 → 글머리표 (또는 표/코드로 지정된 경우 그 형식)
- 시각자료 → 플레이스홀더 도형 + 캡션
- 발표자 노트 → 스피커 노트

먼저 S1~S16(목요일)만 만들고, 끝나면 "완료, 다음 진행?"이라고 알려줘. 내가 확인하면 S17~S30(토요일)을 이어서 만든다.
```
