# CT×AI 마이크로디그리 — 음악 딥러닝 입문 수업 자료

미디어 현업 수강생 대상, 목요일(배경지식)·토요일(실습) 각 25~30분 분량.

| 파일 | 내용 |
|---|---|
| `docs/lecture_plan_music_dl.md` | 수업 계획서. 타임라인, 슬라이드별 개요, 모델별 입력·출력·설정값, 실습 셀 목록, 사전 준비 |
| `docs/slides_spec.md` | 슬라이드별 스펙(S1~S30). 제목·본문·시각자료 캡션·발표자 노트 |
| `docs/slides_prompt.md` | Google Slides의 Claude 사이드 패널에 넣을 프롬프트. `slides_spec.md`와 함께 사용 |

다루는 모델: online AMT, Demucs, YourMT3+, allin1, DDSP Tone Transfer, Stable Audio 3 Medium.

계획서에 나오는 리포트 HTML, 실습 노트북, 모델 가중치, 예시 음원은 이 저장소에 포함하지 않는다. 상업 음원이 들어 있거나 파일 크기가 GitHub 한도를 넘기 때문이다.
